### 📌`robots.txt`

- A **text file** placed in the root of a website (e.g., ***`https://example.com/robots.txt`***  ).
- Purpose: tells **web crawlers / search engines** (like Google, Bing) which pages or sections **they are** **allowed or not allowed** to crawl.

### 📌 `sitemap.xml`

- An **XML file** (structured data) also placed in the root of a website (e.g., ***`https://example.com/sitemap.xml`*** ).
- Purpose: provides a **list of all important pages** on the website so search engines can discover and index them more easily.
