# 🌐 What is theHarvester?

- **theHarvester** is an **open-source reconnaissance tool** written in Python.
- Its purpose: **collect emails, subdomains, IPs, and employee names** related to a domain from **public sources**.
- It is included by default in **Kali Linux**.

# 🛠 What theHarvester Can Do

1. **Email addresses** – finds company emails from search engines and public datasets.
2. **Subdomains** – discovers subdomains of the target domain.
3. **Hosts/IPs** – gathers IP addresses and DNS records.
4. **Employee names / people** – from LinkedIn, social media, etc.
5. **Banners** – can grab server banners (optional).
6. **Integration with APIs** – uses sources like Shodan, Censys, Hunter.io, etc.
