# 🌐 What is WAFW00F?

**WAFW00F** is an **open-source tool** used to **detect Web Application Firewalls (WAFs)** protecting a website.

#Commands:
- wafw00f myclouddoor.com

- Written in **Python**.
- Pre-installed in **Kali Linux**.
- Commonly used during **penetration testing** in the **reconnaissance phase**.

# 🛠 What WAFW00F Does

1. **Identifies if a website is behind a WAF**.
2. **Fingerprints the specific WAF vendor**, e.g.:

    - Cloudflare
    - AWS WAF
    - Imperva Incapsula
    - F5 BIG-IP ASM
    - Akamai Kona Site Defender
    - ModSecurity
    - Barracuda WAF

3. Helps pentesters adjust their attacks:

    - If a WAF is detected, they may need **WAF bypass techniques**.
    - If no WAF is detected, they can target the server directly.
