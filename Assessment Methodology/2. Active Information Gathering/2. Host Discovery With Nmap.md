
# 1. (SYN Scan) It will Identify the Windows Systems

It sent SYN scan to identify the systems, Windows systems allow the SYN packets.

- **nmap -sn -PS1-1024 192.168.23.0/24**
- **nmap -sn -PS1-1024 192.168.23.0/24** --send-ip

	 - -sn is used to skip the port scan and as well as it will sent ICMP and ARP packets to find Host.
	 -  -PS Specific used to SYNC PING (Sent SYNC Packets) after I used 1-1024 ports to get an RST reply from Host.

# 2. (PingSweeps technique) Not Identify the Windows Systems

PingSweeps technique sent ICMP packets to Identify the Hosts. Some windows systems or Firewalls are blocked the ICMP messages, so by using this we can miss our targets.

Command:
- nmap -sn 192.168.23.0/24

#Useages -sn is used to avoid any port scanning, we want to know other IPs in my local network.
