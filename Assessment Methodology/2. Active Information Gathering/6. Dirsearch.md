# 🛠 Features of dirsearch

✅ **Multi-threaded** (fast scanning).  
✅ **Recursive scanning** (goes deeper into found directories).  
✅ Supports **custom wordlists**.  
✅ Can **filter by status codes** (e.g., show only 200/403).  
✅ Supports **proxy** (Burp, etc.).  
✅ Can save results to file.  
✅ Works on **Windows, Linux, macOS** (since it’s Python-based).

#Command 
- dirsearch -u http://target.ine.local
