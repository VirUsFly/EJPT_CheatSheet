1. Check the target network range via Host Discovery
	 - ifconfig (Our Target is eth1)
2. Scan the target network to identify Systems
	- nmap -sn -PS 192.168.5.0/24
3. Aggressive OS scan  
	 - nmap -sS -sV -O --osscan-guess  -p- 192.168.5.52
4. Aggressive Version Scan
	 - nmap -sS -sV --version-intensity 8 -p- 192.168.5.52
5. Both in one line
	 - nmap -sS -sV --version-intensity 8 -O --osscan-guess -p- 192.168.5.52
