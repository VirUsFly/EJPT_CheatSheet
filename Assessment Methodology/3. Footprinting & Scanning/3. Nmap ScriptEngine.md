1. Search Nmap Scripts
	 - ls /user/share/nmap/scripts | grep "http"
2. Get Help of a Script
	 - nmap --script-help=memcached-info
3. Default Scan
	 - nmap -sS -sV -sC -p- 192.168.5.55
4. Specific scan
	 - nmap -sS -sV --script=memcached-info -p- 192.168.5.55
5. All a Specifc script
	 - nmap -sS -sV --script=memcahced-* -p- 192.168.5.55
